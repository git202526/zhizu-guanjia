# 智租管家 · 个人房东租房管理应用

单文件 HTML 应用（零后端、零安装），数据保存在浏览器本地（localStorage），手机 / 电脑浏览器打开即可使用。

## 功能

- **工作台**：收支结余、本月应收 / 实收 / 支出、空置率、逾期催收与合同到期提醒
- **房源**：小区分组、状态色卡（已租 / 空置 / 逾期 / 将到期）、签约 / 续租 / 退租 / 编辑
- **租客**：按姓名 / 电话 / 房号搜索，合同与账单一览
- **账单收租**：电子照片账单（Canvas 生成 PNG 下载）、58mm 小票打印、催收文案复制、标记 / 撤销到账
- **水电抄表**：水表录入读数自动算费并入账单；电表预付费不抄表，充值到账登记为电费收入；计费方式每间可配置
- **收支报表**：租金总账 + 电费专账 + 水费专账三本账盈亏（红盈绿亏）、近 6 月收支图、收入构成图、流水明细
- **合同中心 / 设置 / 数据管理**：续租退租、日 / 夜主题（浅蓝清爽 / 深色高级）、水电单价、收租提醒、JSON 导出导入与重置

## 使用

直接打开 [在线地址] 或下载 `index.html` 用浏览器打开。首次打开自带一套口径自洽的示例数据，可在「我的 → 数据管理」中清空后录入真实数据，或导出 / 导入 JSON 备份。

## 技术说明

- 纯 HTML + CSS + JavaScript（原生 ES5/ES6），ECharts 走 jsDelivr CDN（离线时图表区显示降级提示）
- 数据存 `localStorage`，不上传服务器；换设备前请先导出备份
- 主题切换：顶栏月亮按钮 或 设置 → 主题（日间 / 夜间 / 跟随系统）
